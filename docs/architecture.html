System Architecture

Factory Inventory Management System

A full-stack demo application for tracking inventory, orders, demand forecasts, backlog, and spending across warehouses. Built with a Vue 3 frontend and a Python FastAPI backend serving in-memory mock data — no database.

1Tech Stack

Frontend

Vue 3 + Vite

  • Vue 3 Composition API
  • Vue Router (client-side routing)
  • Axios (HTTP client)
  • Vite dev server — localhost:3000
Backend

Python + FastAPI

  • FastAPI application (main.py)
  • Pydantic models for validation
  • Uvicorn ASGI server — localhost:8001
  • CORS enabled for local dev
Data

In-Memory JSON

  • Static JSON files in server/data/
  • Loaded at startup by mock_data.py
  • No database — data resets on restart

Four filters — Time Period, Warehouse, Category, Order Status — are held in shared reactive state and passed as query parameters on every relevant API call. Raw API responses are stored in refs (e.g. allOrders, inventoryItems); everything derived for display (totals, chart series, filtered lists) lives in computed properties so it recalculates automatically as filters change.
